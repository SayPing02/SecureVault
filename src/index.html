How It Works
// Shamir's (K, N) Secret Sharing Scheme + AES-256-GCM Encryption
The Hybrid Scheme
🔑
1. Encrypt
The whole file is encrypted once with a random 256-bit AES key using AES-256-GCM.
✂️
2. Split the key
Only the small AES key is split with Shamir's Secret Sharing into N shares. This keeps every fragment tiny.
🧩
3. Package
Each fragment carries one key share plus a copy of the ciphertext. Any K fragments rebuild the file; K-1 reveal nothing.
Key Properties
🔒
Perfect Secrecy
Any K-1 fragments reveal zero information about the key. Mathematically proven.
♻️
Fault Tolerance
Up to N-K fragments can be lost without affecting recovery.
🎲
GF(256) Arithmetic
Byte-level polynomial evaluation over a Galois Field for exact integer arithmetic.
🛡️
Encrypted at Rest
Fragment files in the vault are themselves AES-encrypted, unreadable outside the app.
Optional Password Layer
🔐
When you set a password, the AES key is itself encrypted with a PBKDF2-derived key before being split. Even someone holding K fragments cannot reconstruct the file without the password.
