Frequently Asked
Does SecureVault need an internet connection?
No. Splitting, encryption and reconstruction all happen on this device. There are no accounts and no servers, so there is nothing to sign in to and nothing sent anywhere.
What happens if I forget my PIN?
Use your recovery code. On the lock screen choose Forgot your PIN?, enter the code, and set a new PIN.

If you never saved a recovery code, a forgotten PIN cannot be recovered. Your PIN is never stored anywhere — there is nothing to look up, by you or by anyone else.
I've lost my recovery code. What should I do?
While you can still open the vault, go to Settings → Recovery Code → Replace. That issues a new code and retires the old one.

Do this before you get locked out: a recovery code can only be replaced from inside a vault you can still open.
What if I lose one of my fragments?
As long as you still have at least the threshold number you chose when adding the file, it rebuilds normally — that's the point of the threshold. Below it, the file cannot be reconstructed. That limit is the security guarantee working as intended, not a fault.
What does "Rotate Fragments" actually do?
It re-splits the file with a brand-new key, so fragments you handed out earlier stop working against your vault — useful when you no longer trust where an old fragment ended up.

It does not reach out and erase copies someone already holds. It makes them useless going forward, which is the most any system can do.
What happens if my hard drive fails?
Your vault exists only on this device, so back it up: Settings → Backup & Restore → Back Up Vault. That produces a single password-protected file you can keep on a USB drive or in a cloud folder.

The backup password is separate from your PIN, and it cannot be recovered if forgotten.
Which encryption option should I pick?
The one shown by default. It's chosen automatically based on your hardware and the file's size, and you can use it without thinking about it. All four options — AES-256-GCM, ChaCha20-Poly1305, XChaCha20-Poly1305 and AES-256-GCM-SIV — are strong authenticated ciphers; the differences are about speed and safety margins, not about one being weak.
Can anyone recover my files for me?
No. There is no account, no server and no master key. Nobody — including the developer — can open your vault or reset your PIN.

That's deliberate, and it's exactly why your recovery code and your vault backup matter so much.
Has the security been independently audited?
Not yet. SecureVault uses standard, widely reviewed cryptography — AES-256-GCM, ChaCha20-Poly1305, Argon2id and Shamir Secret Sharing — rather than anything custom-built, and the fragment logic is covered by an automated test suite. But it has not had a third-party security audit, and it's fair to weigh that when deciding what to trust it with.
Where is my vault stored on disk?
In the app's own data folder — Application Support/com.securevault.app on macOS, the equivalent AppData location on Windows. Everything in it is encrypted and isn't meant to be edited by hand.
